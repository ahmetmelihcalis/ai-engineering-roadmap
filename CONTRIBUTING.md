# Contributing

Small, focused contributions are welcome. Content corrections, broken links, clearer examples, and improvements to the Turkish or English roadmap notes are especially useful.

## Before you open a pull request

- Check whether an issue already covers the same change.
- Keep Turkish and English counterparts aligned when the change applies to both.
- Prefer official documentation or primary sources for technical links.
- Keep code examples executable and avoid unrelated formatting changes.

## Local checks

Run these before opening a pull request:

```bash
npm run lint
npm run check:content
```

## Pull requests

Explain what changed and why. For roadmap content, include the affected page links and mention whether the matching translation was updated. One focused pull request is easier to review than a broad cleanup.
